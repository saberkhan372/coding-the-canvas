Functions

A function is a named drawing command. Write it once, call it anywhere. Parameters let the same function draw different things each time.

Try it in the Playground §4 Section overview

Concept 07 / 22

The big idea

Repeated drawing code is the smell that a function is needed. Once you name the operation — drawFlower(x, y, size) — you can place dozens of flowers in a loop with one line each. Parameters make the function flexible; return values let it compute something back.

  • function name(param1, param2) { } — definition
  • name(arg1, arg2) — calling (invoking) the function
  • Parameters are local variables — they only exist inside the function
  • return sends a value back to the caller
  • A function that draws something doesn't need to return
  • DRY: Don't Repeat Yourself — the motivation for functions

// define once
function drawHouse(x, y, size) {
  // walls
  rect(x, y, size, size * 0.8);
  // roof triangle
  triangle(
    x,            y,
    x + size,     y,
    x + size/2,  y - size * 0.5
  );
  // door
  rect(x + size*0.35, y + size*0.4,
       size*0.3, size*0.4);
}

function draw() {
  background(240);
  // call three times — different positions & sizes
  drawHouse(40,  180, 80);
  drawHouse(180, 200, 60);
  drawHouse(290, 160, 100);
}

function drawHouse(ctx, x, y, size) {
  ctx.fillRect(x, y, size, size * 0.8);
  ctx.beginPath();
  ctx.moveTo(x, y);
  ctx.lineTo(x + size, y);
  ctx.lineTo(x + size/2, y - size * 0.5);
  ctx.closePath();
  ctx.fill();
}

The canvas idea

Start with a sketch that draws the same shape in three places using copy-pasted code. Ask: "what if I want to change the color of every copy?" They'd have to edit three places. A function fixes that — edit once, update everywhere.

Then put the function call inside a for loop: for (let i = 0; i < 10; i++) drawHouse(i*80, 200, 60) — instant row of houses.

Function anatomy

function drawFlower(
  x,     // parameter 1
  y,     // parameter 2
  size   // parameter 3
) {
  // body: runs when called
  circle(x, y, size);
}

Teacher notes

Timing: 2 periods. "Refactor" a repetitive sketch into a function — the motivation is built in.

Key distinction: A function definition is a recipe. A function call is cooking from the recipe. Defining it doesn't run any code.

AP CSA: Methods, parameters, and return types are core to Unit 2. The canvas makes the call/return cycle visible.
