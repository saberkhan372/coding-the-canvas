visual computer science

Coding the Canvas

A hands-on CS curriculum where students learn programming by making images, animations, interactions, and data-driven sketches.

Make computer science visible.

Coding the Canvas is a visual path into CS: students draw, animate, listen for input, work with pixels and data, then use those sketches to understand algorithms, abstraction, impact, and Java-ready ideas.
