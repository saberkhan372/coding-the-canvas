Arrays

An array is an ordered list. Give it one name, store many values. Index [0] is the first item. Loop through it to draw everything at once.

Try it in the Playground §4 Section overview

Concept 08 / 22

The big idea

An array stores multiple values under a single variable name. Instead of x1, x2, x3..., you have positions[0], positions[1], positions[2]... — and you can loop through all of them with one for loop. This is how a sketch goes from "a few shapes" to "a crowd."

  • let arr = [10, 20, 30] — array literal
  • arr[0] — first item (index starts at 0)
  • arr.length — number of items
  • arr.push(value) — add to the end
  • for (let i = 0; i < arr.length; i++) — classic traversal
  • for (let val of arr) — modern for-of loop

let xPositions = [];
let yPositions = [];
let sizes = [];

function setup() {
  createCanvas(400, 300);
  // fill arrays with random values
  for (let i = 0; i < 50; i++) {
    xPositions.push(random(width));
    yPositions.push(random(height));
    sizes.push(random(4, 16));
  }
}

function draw() {
  background(20);
  fill(255);
  noStroke();
  // draw all 50 stars from the arrays
  for (let i = 0; i < xPositions.length; i++) {
    circle(xPositions[i], yPositions[i], sizes[i]);
  }
}

const stars = [];
for (let i = 0; i < 50; i++) {
  stars.push({
    x: Math.random() * canvas.width,
    y: Math.random() * canvas.height,
    r: Math.random() * 6 + 2
  });

const ctx = canvas.getContext('2d');
ctx.fillStyle = '#141410';
ctx.fillRect(0, 0, canvas.width, canvas.height);
ctx.fillStyle = 'white';

for (const star of stars) {
  ctx.beginPath();
  ctx.arc(star.x, star.y, star.r, 0, Math.PI * 2);
  ctx.fill();
}

The canvas idea

Start with one circle, then ask: "how would you store the positions of 50 circles?" Students will try variables — x1, x2... — and quickly see why that doesn't scale. An array stores all 50 positions, and a loop draws them all.

Common patterns

  • Store x/y positions, sizes, colors in parallel arrays
  • Or store objects: [{x:10, y:20}, ...]
  • Use arr.length not a hard-coded count
  • arr[arr.length-1] — last item
  • Off-by-one: i < arr.length, not i <= arr.length

Teacher notes

Timing: 1–2 periods. Pairs naturally with Objects (09) — once students have arrays of numbers, they're ready for arrays of objects.

AP CSA: Arrays (ARR-1, ARR-2) are a major unit. The canvas gives every array index a visible location in space, making off-by-one errors immediately obvious.
