concept bridge

Arrays: One Thing to Many Things

A bridge from single variables to indexed collections of related values.

Move from one object to a collection.

Students understand one ball before they understand fifty. This bridge makes the shift explicit: the same properties still exist, but now they live in a list and a loop visits each one.

  • Start with one visible object and name its properties.
  • Replace repeated variables with indexed positions.
  • Use a loop to update and draw every item.

Bridge moves

One thing

Draw one circle with x, y, and speed. Ask what changes if the sketch needs ten circles.

Many values

Collect related x values in one array so index 0, 1, and 2 become visible handles.

One rule

Use a loop so every item follows the same update-and-draw rule.

Teacher move

Let students try x1, x2, x3 first. The awkwardness creates the need for arrays.

Common snag

Students often mix up the index and the value stored at that index. Point to both on the canvas.

AP connection

This bridge supports list traversal, parallel arrays, ArrayList, and object collections.

p5.js pattern
let xs = [40, 90, 140];
let ys = [80, 60, 100];

function draw() {
  background(246);
  for (let i = 0; i < xs.length; i++) {
    circle(xs[i], ys[i], 24);
    xs[i] += 1;
  }
}
