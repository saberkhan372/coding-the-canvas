Recursive Branch Garden

A tiny recursive tree where each branch draws two smaller branches until the base case stops.

Open p5.js editor All sketches

What this seed teaches

This seed pairs recursion with push/pop: each branch gets its own local world, then returns to the parent branch.

p5.js starter
function setup() {
  createCanvas(500, 360);
  angleMode(DEGREES);
  noLoop();
}

function draw() {
  background(246, 242, 234);
  translate(width / 2, height - 30);
  stroke(28);
  branch(85);
}

function branch(len) {
  line(0, 0, 0, -len);
  translate(0, -len);

  if (len < 12) {
    fill(217, 106, 61);
    noStroke();
    circle(0, 0, 8);
    stroke(28);
    return;
  }

  push();
  rotate(28);
  branch(len * 0.68);
  pop();

  push();
  rotate(-24);
  branch(len * 0.72);
  pop();
}

Try this

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Change the branch angles and describe the tree personality.
  • Change the base case from 12 to 5 or 25.
  • Add a third branch or color by recursion depth.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
