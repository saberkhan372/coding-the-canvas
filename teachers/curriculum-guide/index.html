The seven-section arc

Coding the Canvas is organized as a progressive arc from first drawing to systems thinking. Each section builds on the previous. The canvas is the proof: students see their own learning compound on screen.

  • Sections map to AP Big Ideas and CS A Units
  • Each concept fits one class period (30–50 min)
  • Sections 1–4 form a strong standalone unit (~12 periods)
  • Sections 5–7 extend into data, impact, and algorithms
  • Processing (Java) column throughout for AP CS A

Prerequisite knowledge

Students entering §1 should be comfortable with:

variables arithmetic operators basic data types reading error messages

No prior graphics experience needed. The canvas is the entry point, not a reward.

Suggested sequences

  • Full arc: §1 → §7 in order (~24 weeks)
  • Standalone CSP unit: §1–§4 + §6 (~16 weeks)
  • CS A supplement: §1–§5 + §7 (~20 weeks)
  • Workshop / bootcamp: §1 + §4 only (~5 days)
  • Data deep dive: §1–§2 then §5

Language paths

p5.js — browser-based, no install. All interactive editors run in the page. Best for general CS or CSP courses.

Canvas API — shows what p5 does under the hood. Best for web fundamentals or "no magic" classes.

Processing (Java) — read-and-copy Java that runs in the Processing IDE. Best for AP CS A and Java-centered classrooms.

Ten years of CC Fest, distilled

"Change one thing. See what happens."

The canvas is the feedback loop. Every edit is an experiment with an immediate visual result.

"Intuition before syntax."

Name the visual idea before writing the code that produces it. Description comes first.

"Play before reading."

Open the interactive tool before reading the concept page. Questions come from doing, not from reading about doing.
