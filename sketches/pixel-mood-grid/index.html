Pixel Mood Grid

A hand-coded bitmap where 0s and 1s become pixels, then colors turn the grid into a tiny mood icon.

Open p5.js editor All sketches

What this seed teaches

This is a concrete bridge from binary data to image data: the string is the picture before it is drawn.

binarypixelscolorgrid
p5.js starter
let bits = [
  "00111100",
  "01111110",
  "11011011",
  "11111111",
  "11100111",
  "01111110",
  "00111100",
  "00000000"
];

function setup() {
  createCanvas(500, 320);
  noLoop();
}

function draw() {
  background(246, 242, 234);
  let size = 28;
  let startX = 138;
  let startY = 48;

  for (let row = 0; row < bits.length; row++) {
    for (let col = 0; col < bits[row].length; col++) {
      if (bits[row][col] === "1") fill(217, 106, 61);
      else fill(236, 229, 214);
      stroke(28);
      square(startX + col * size, startY + row * size, size);
    }
  }
}

Try this

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Change the 0/1 pattern to make a new icon.
  • Use three symbols instead of two and map each to a color.
  • Add labels that explain how many bits wide and tall the image is.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
