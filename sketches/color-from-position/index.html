Color From Position

Move the mouse and watch position become color, a direct path into mapping and 24-bit RGB thinking.

Open p5.js editor All sketches

What this seed teaches

This is a compact bridge from input to representation: position is not color, but code can translate it into color.

mousecolormaprgb
p5.js starter
function setup() {
  createCanvas(500, 320);
}

function draw() {
  let redAmount = map(mouseX, 0, width, 0, 255);
  let blueAmount = map(mouseY, 0, height, 255, 0);

  background(redAmount, 80, blueAmount);
  fill(255);
  noStroke();
  circle(mouseX, mouseY, 42);
}

Try this

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Map mouse position to size, opacity, or stroke weight.
  • Add text that prints the current RGB values.
  • Clamp or exaggerate the mapped range and compare the effect.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
