Simple Collision Game

A tiny target game where distance becomes a win condition and state gives the sketch a mode.

Open p5.js editor All sketches

What this seed teaches

This is a friendly bridge from conditionals to state machines: one condition changes the whole screen.

gamedistanceconditionalsstate
p5.js starter
let targetX = 380;
let targetY = 160;
let won = false;

function setup() {
  createCanvas(500, 320);
}

function draw() {
  background(won ? "#d7f0df" : "#f6f2ea");

  fill("#d96a3d");
  circle(targetX, targetY, 46);

  fill("#1c1a17");
  circle(mouseX, mouseY, 28);

  if (dist(mouseX, mouseY, targetX, targetY) < 37) {
    won = true;
  }

  textSize(24);
  text(won ? "You found it." : "Move to the target.", 24, 42);
}

Try this

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Add a timer or score.
  • Move the target after each win.
  • Add start/play/win states instead of one boolean.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
