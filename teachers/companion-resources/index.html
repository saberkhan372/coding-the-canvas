Companion Resources

Recommended add-ons for the one real gap (CSN) and optional enrichment for impact, data ethics, and context beyond the canvas.

AP CSP gap analysis Curriculum guide

Honest about the gaps

CS Canvas covers 4 of 5 AP CSP Big Ideas.

The one it doesn't cover is CSN — Computing Systems & Networks (internet, protocols, fault tolerance, parallel computing). Teaching this through a canvas feels forced — the canvas is the wrong medium for networking concepts. You'll need to bring your own CSN unit. Here's what works well alongside CS Canvas.

  • CSN is ~3 weeks — a manageable add, not a big gap
  • Most AP CSP teachers already have a CSN unit they like
  • Canvas-based lessons exist as enrichment, not replacements
  • Impact and ethics lessons (§6) can be extended with readings
CSN Gap — Computing Systems & Networks

The honest recommendation: use what you already have. Most AP CSP teachers have a CSN unit they like. If you don't, here are three that slot in cleanly.

free · interactive
code.org AP CSP — Internet unit
The best free CSN unit available. Covers packets, DNS, protocols, encryption, and fault tolerance through unplugged activities and simulations. Usually 2–3 weeks. Works standalone — you don't have to use the rest of code.org's curriculum.
video series · flipped
How the Internet Works — code.org videos
Six 5-minute videos covering IP, TCP, HTTP, encryption, and the web. Best as a flipped or at-home component alongside another CSN activity. Useful for visual learners and as a review before the AP exam.
physical · unplugged
CS Unplugged — Network Protocols
Offline activities that simulate routing and packet loss through physical card games. Great for schools without consistent internet access or for kinesthetic learners. Pairs well with a short reading on TCP/IP.
§6 Enrichment — Impact & Ethics

The §6 lessons (Bias, Accessibility, Authorship, Energy) are intentionally short. Add readings, case studies, or discussions to deepen any of them.

reading · bias
"Coded Bias" — documentary + discussion guide
Pairs directly with Concept 17 (Bias in a Filter). Shows real-world facial recognition failures. The discussion guide has structured questions for 9–12 students. 90-minute film or use clips. Available on Netflix.
tool · accessibility
WebAIM Contrast Checker
Free browser tool for checking contrast ratios between two colors. Students use it alongside Concept 18 (Color & Accessibility) to evaluate their own palettes. Immediate feedback loop — pairs directly with the canvas output.
reading · authorship
The Computer as a Creative Partner — Harold Cohen
Cohen's AARON program (1970s generative art) is the canonical case for the authorship question in Concept 19. Short accessible essays available online. Ask students: was Cohen the artist, or was AARON?
data · energy
Our World in Data — Energy & Computing
Free charts on data center energy use, global electricity consumption, and computing's environmental footprint. Pairs with Concept 20 (Energy of a Sketch). Students can look up the energy cost of streaming, training a model, or loading a page.

Optional enrichment — for any section

reference · p5.js
p5.js Reference
The canonical documentation for p5.js functions. Bookmark it — students should learn to look things up here. Every function used in CS Canvas is in the reference. The examples page shows many of the same visual concepts.
book · creative coding
The Nature of Code — Daniel Shiffman
Free online book that extends §4 (Objects, Arrays) into physics simulation: forces, steering, flocking. Perfect enrichment for students who finish the curriculum early. The p5.js version mirrors CS Canvas's language.
reference · canvas api
MDN Canvas API Documentation
The authoritative reference for the Canvas 2D API. Students using the Canvas API track should bookmark this. The tutorials section includes a pixel manipulation guide that pairs well with §5.
tool · Processing Java
Processing IDE + Reference
The desktop environment where Processing (Java) sketches run. Free, cross-platform, no dependencies. The Reference tab in the IDE is instant documentation — students can right-click any function. AP CS A teachers should ensure all students have this installed before §4.

Pairing principle

The best companion resources share one trait: they connect back to something visible. If the reading or video can produce a canvas artifact — a chart, a filter, a sketch — use it. If it can't, keep it short (10–15 min) and pair it with a discussion prompt, not a coding exercise.

For AP CSP teachers

Your core gap is CSN (~3 weeks). Everything else in AP CSP is covered by CS Canvas. The code.org Internet unit is the path of least resistance. If your district already has a CSN unit you like, use that. See the AP CSP coverage page for the full picture.

For AP CS A teachers

CS Canvas covers all 10 AP CS A units — there's no structural gap to fill. Companion resources here are enrichment only. The biggest addition that helps CS A students: more FRQ practice beyond the concepts. See the FRQ Practice page.
