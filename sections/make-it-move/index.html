Make It Move

Time, animation, the draw loop — and the insight that changing one number every frame makes things come alive.

Start Concept 03 Open Playground

Concept 03  ·  Animation focus

What this section covers

The jump from a static sketch to an animated one is conceptually huge. Students discover that draw() runs 60 times a second and that every variable update inside it becomes visible motion. The key idea: time is just a counter, and any changing value can be mapped to position, size, or color.

  • setup() runs once; draw() loops forever
  • frameCount as a time variable
  • State variables that accumulate each frame
  • background() to clear vs. trail effects without clearing
  • frameRate() and performance awareness

Teacher framing

Key demo: Open p5.js, remove background() from draw() and watch the trail appear. Ask: "what changed?" Then add it back. The visual diff does the teaching.

Checkpoint: Students can explain in writing why setup() and draw() are separate functions, and can make a shape move across the canvas then wrap around.

Learner framing

Your sketch is now a movie. Each call to draw() is one frame. If you change a number by 1 every frame, that number becomes motion — left-right, up-down, growing, shrinking.

The loop isn't magic — it's just a function that keeps getting called. Once you see that, you can control time.

Common misconceptions

  • draw() doesn't animate by itself — you need changing values
  • The canvas doesn't erase unless you call background()
  • frameCount starts at 0, not 1
  • Variables declared inside draw() reset every frame
