Mouse Trail Drawing

A drawing tool where the mouse leaves memory behind, turning interaction into an array-backed sketch.

Open p5.js editor All sketches

What this seed teaches

This sketch makes arrays feel like memory: the canvas remembers where the mouse has been.

mousearraysinteractiontrail
p5.js starter
let marks = [];

function setup() {
  createCanvas(500, 320);
}

function draw() {
  background(246, 242, 234, 35);
  marks.push({ x: mouseX, y: mouseY });

  if (marks.length > 80) {
    marks.shift();
  }

  noStroke();
  for (let i = 0; i < marks.length; i++) {
    let size = map(i, 0, marks.length, 4, 28);
    fill(217, 106, 61, 140);
    circle(marks[i].x, marks[i].y, size);
  }
}

Try this

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Store color or size in each mark.
  • Draw lines between neighboring marks.
  • Only add a mark when the mouse is pressed.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
