Data Self-Portrait

A tiny handmade dataset becomes a visual self-portrait, showing that data choices are design choices.

Open p5.js editor All sketches

What this seed teaches

Frame this as “same data, different visual story.” Ask what the chart shows and what it hides.

dataarraysmapportrait
p5.js starter
let values = [7, 4, 9, 3, 6];
let labels = ["sleep", "focus", "music", "outside", "energy"];

function setup() {
  createCanvas(500, 320);
}

function draw() {
  background(246, 242, 234);
  for (let i = 0; i < values.length; i++) {
    let h = map(values[i], 0, 10, 20, 190);
    let x = 70 + i * 85;
    fill(217, 106, 61);
    rect(x, height - 55 - h, 42, h);
    fill(28);
    textAlign(CENTER);
    text(labels[i], x + 21, height - 28);
  }
}

Try this

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Replace the values with data about your day, class, or neighborhood.
  • Try circles instead of bars and compare what the viewer notices.
  • Add a title and source note.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
