Pattern Logic

See it, say it, code it — turning visual rules into loops, conditions, and map() expressions that scale data to the canvas.

Describe it before you code it.

Pattern logic asks students to say the rule out loud before writing it. Once the visual decision is named — "every even column is orange, every odd is dark" — loops, conditionals, and map() become tools for expressing it, not arbitrary syntax to memorize.

  • Circle what repeats. Underline what changes.
  • Translate each visual decision into one sentence.
  • Change one thing at a time — predict before running.
  • Use map() to scale raw data values to canvas dimensions.

Common misconception

"Data visualization is a specialized field — not something you do with a for loop." — Every bar chart, dot plot, and heat map students have seen is a for loop with a visual decision inside. Reading data, scaling it with map(), and drawing it is the whole job.

Bridge moves

See it

Show a pattern. Ask students to circle what repeats and underline what changes. Keep the code editor closed — describe it first.

Say it

Turn the observation into one rule: "every even column is orange." If you can say it in one sentence, you can code it.

Code it

Translate the sentence — a loop variable and a condition. Then: change one thing and predict the result before running.

Discussion question

Which visual property makes large values feel most dramatic — height, size, or color? Which is most subtle?

Follow-up: if you sorted the data before drawing it, would the pattern become clearer or less clear?

Key vocabulary

map() input range output range i % 2 alternation visual encoding

AP connection

Pattern logic supports algorithmic thinking, abstraction, conditionals, and data representation — AP CSP (AAP, DAT) and AP CS A array iteration problems.

visual rule — data drives the drawing 
let data = [40, 85, 60, 20, 95, 55, 70];

function setup() {
  createCanvas(400, 200);
}

function draw() {
  background(246);
  for (let i = 0; i < data.length; i++) {
    // scale raw value to bar height
    let h = map(data[i], 0, 100, 0, height - 40);

    // alternate fill on even / odd index
    fill(i % 2 === 0 ? '#d96a3d' : '#1c1a17');
    noStroke();
    rect(20 + i * 52, height - h - 20, 40, h);
  }
}

3-minute demo script

Step 1. Show a grid loop drawing same-sized circles with no conditions. Ask: "What one rule would make every even column orange?" Let students predict before typing anything.

Step 2. Add if (i % 2 === 0). Run. Change the divisor to 3 — ask "what pattern do you expect?" before running again.

Step 3. Replace uniform sizes with map() driven by a data array. Ask: "which property shows the differences most clearly — height, width, or color?"

Watch for: students changing too many variables at once and losing track of cause and effect. Say: "change one thing, predict what happens, then run." That discipline is half the lesson.
