Noise Walker

A single dot drifts smoothly through noise space, making randomness feel organic instead of jumpy.

Open p5.js editor All sketches

What this seed teaches

Use this next to a `random()` version. Students can feel the difference before naming Perlin noise.

noisemotionsystemsorganic
p5.js starter
let t = 0;

function setup() {
  createCanvas(500, 320);
}

function draw() {
  background(246, 242, 234, 24);

  let x = noise(t) * width;
  let y = noise(t + 100) * height;

  fill(28, 26, 23);
  circle(x, y, 18);
  t += 0.01;
}

Try this

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Change the step size and describe the motion personality.
  • Draw a trail instead of clearing the background completely.
  • Use noise to control color or size too.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
