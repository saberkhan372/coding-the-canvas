Coordinates

Every pixel on the canvas has an address: two numbers, x and y. Learn how to find any point — and why y increases downward.

Try it in the Playground §1 Section overview

Concept 01 / 22

The big idea

A canvas is a grid of pixels. Every pixel sits at an intersection of a column (x) and a row (y). The origin — position (0, 0) — is the top-left corner. x increases to the right. y increases downward — the opposite of the math classroom, and the first thing that surprises every student.

  • Origin (0, 0) is top-left, not bottom-left
  • x moves right, y moves down
  • Canvas width and height set the boundary
  • Pixel positions are integers — no fractions needed
  • Shapes are placed by their top-left corner or center depending on the function

The canvas idea

Start by showing a blank rectangle and asking "where is the center?" Students instinctively point — and then you can show them how to describe that point with two numbers.

Run circle(mouseX, mouseY, 20) first. Students can see coordinates update in real time before any explanation is needed.

Key vocabulary

  • x — horizontal distance from the left edge
  • y — vertical distance from the top edge
  • origin — the (0, 0) point, top-left corner
  • pixel — the smallest addressable unit on screen
  • canvas size — width × height in pixels

Teacher notes

Timing: 1–2 periods. This concept is brief but the y-axis misconception is sticky — plan to revisit it in §2 and §3.

Checkpoint: Students place three circles at exact positions they specify in advance on paper, then verify in code.

AP CSP: Introduces abstraction (a position = two numbers) and procedural notation.

Common misconception: "y=0 is at the bottom." In math class, y increases upward. On screen, row 0 is the top row. Show both axes side by side. Ask students to predict where a shape will appear before running the code.
