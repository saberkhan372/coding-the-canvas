Pixels / Image Data

Every image is a flat array of numbers — 4 values per pixel: R, G, B, A. loadPixels() opens that array. You can read it, filter it, transform it, write it back.

Try it in the Playground §5 Section overview

Concept 11 / 22

The big idea

A 400×300 canvas has 120,000 pixels. Each pixel is stored as 4 consecutive numbers (RGBA) in a flat array — meaning 480,000 values total. The index of pixel (x, y) is: (y * width + x) * 4. Once you can calculate that index, you can read or change any pixel.

  • loadPixels() / updatePixels() — open and close the pixel array
  • pixels[] — the flat RGBA array (4 values per pixel)
  • Index formula: (y * width + x) * 4
  • R is at index i, G at i+1, B at i+2, A at i+3
  • Grayscale: set R = G = B to the same value
  • Invert: set R = 255 - R, G = 255 - G, B = 255 - B

The index formula

// pixel at column x, row y in a canvas of given width let index = (y * width + x) * 4; pixels[index] // Red (0–255) pixels[index + 1] // Green (0–255) pixels[index + 2] // Blue (0–255) pixels[index + 3] // Alpha (0–255, 255 = fully opaque)

function setup() {
  createCanvas(400, 300);
}

function draw() {
  // draw something first
  background(120);
  fill(217, 106, 61);
  circle(200, 150, 120);

  // now manipulate the pixel array
  loadPixels();

  for (let i = 0; i < pixels.length; i += 4) {
    pixels[i]     = 255 - pixels[i];     // R
    pixels[i + 1] = 255 - pixels[i + 1]; // G
    pixels[i + 2] = 255 - pixels[i + 2]; // B
    // leave alpha (i+3) alone
  }

  updatePixels();
}

void setup() { size(400, 300); }

void draw() {
  background(120);
  fill(217, 106, 61);
  ellipse(200, 150, 120, 120);

  loadPixels();
  for (int i = 0; i < pixels.length; i++) {
    color c = pixels[i];
    pixels[i] = color(
      255 - red(c),
      255 - green(c),
      255 - blue(c)
    );
  }
  updatePixels();
}

The canvas idea

Draw a simple shape, then run the invert filter. The result is immediate and striking — and students can see that every visual change was produced by arithmetic on numbers.

Next: grayscale — replace R, G, B with their average: (R+G+B)/3. Students often try to set just one channel; seeing why that doesn't work (red tint) teaches how color channels work.

Common filters

  • Invert: 255 - each channel
  • Grayscale: R=G=B=(R+G+B)/3
  • Threshold: if brightness > 128, white; else black
  • Red channel only: set G=0, B=0
  • Brightness: multiply each channel by a factor

Teacher notes

Timing: 2 periods. The index formula (y*width+x)*4 deserves its own whiteboard moment.

AP CSP: Pixel data is a concrete example of how images are represented as binary data (DAT-1.A). This is tested on the AP exam.

Performance note: Pixel manipulation is slow if done every frame. Explain why — and introduce noLoop() for one-shot filters.
