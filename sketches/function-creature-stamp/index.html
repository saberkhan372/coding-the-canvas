Function Creature Stamp

A small creature-drawing function called several times with different arguments.

Open p5.js editor All sketches

What this seed teaches

Let students copy the creature three times first, then ask what should become a parameter.

functionsparametersreusecreature
p5.js starter
function setup() {
  createCanvas(500, 320);
  noLoop();
}

function draw() {
  background(246, 242, 234);
  drawCreature(120, 170, 70, "#d96a3d");
  drawCreature(250, 130, 52, "#1c1a17");
  drawCreature(370, 190, 88, "#6aa7a0");
}

function drawCreature(x, y, size, bodyColor) {
  fill(bodyColor);
  circle(x, y, size);
  fill(255);
  circle(x - size * 0.15, y - size * 0.12, size * 0.18);
  circle(x + size * 0.15, y - size * 0.12, size * 0.18);
}

Try this

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Add a mouth, legs, or antennae to the function.
  • Add a parameter for mood or eye size.
  • Use a loop to stamp a whole row of creatures.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
