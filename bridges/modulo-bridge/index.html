Modulo: Counting in Cycles

The % operator turns any growing counter into a repeating cycle — position wrap, color alternation, and animation on a beat.

Numbers that loop instead of grow.

Modulo is easiest to feel when something wraps: a dot leaves the right edge and returns on the left, colors repeat every third item, a clock resets after 12. The key insight is that % isn't a formula to memorize — it's a question: "how far around the cycle am I?"

  • Name the pattern before naming the operator.
  • Use % to keep values inside a fixed range.
  • Alternate choices with i % 2 — no long if/else chain needed.
  • Animate on a beat with frameCount % n.

Common misconception

"% is just a math leftover — I don't need it for visual work." — Students also read % as percent. Say "remainder after division" every time at first. The visual payoff — wrapping motion, alternating colors, on-beat pulses — makes the operator stick faster than any definition.

Bridge moves

Name the cycle

A clock resets at 12. A dot wraps at the canvas edge. Colors repeat every 3 items. Name the thing that loops before writing any code.

Wrap position

Use x = (x + speed) % width so motion stays on canvas forever. Ask: what is the remainder when x equals width exactly?

Debug the pattern

Print i and i % n side by side. Count aloud as the sequence repeats — 0, 1, 2, 0, 1, 2. The repetition is the whole idea.

Discussion question

What does frameCount % 60 equal at frame 59? Frame 60? Frame 61?

Follow-up: if you want something to pulse every 2 seconds at 30 fps, what divisor would you use?

Key vocabulary

% modulo remainder cycle frameCount width

AP connection

Modulo appears in loop patterns, bounds checking, grid row/column logic, and algorithmic thinking — core to AP CSP (AAP) and AP CS A iteration problems.

wrapping motion + alternating style 
let x = 0;

function draw() {
  background(246);

  // wrap: dot returns when it leaves the right edge
  x = (x + 3) % width;

  // alternate fill on every other position slot
  let slot = floor(x / 60) % 2;
  fill(slot === 0 ? '#d96a3d' : '#1c1a17');

  circle(x, height / 2, 30);
}

3-minute demo script

Step 1. Draw a number line 0–8 on the whiteboard. Bend it into a circle so that 3 connects back to 0. "Modulo tells you where you are on this circle."

Step 2. Count from 0 to 8 with divisor 3. Say each remainder aloud before running any code: "0, 1, 2, 0, 1, 2, 0, 1, 2." The pattern is the payoff.

Step 3. Code the wrapping dot. Set x = width manually. Ask: "what does width % width give us?" (0 — it teleports to the left.)

Watch for: students thinking % gives 0 when the counter exactly hits the divisor is surprising — make that moment explicit because that is exactly why wrapping works.
