Concept 03 / 22  ·  §2 Make It Move

Draw Loop / Time

setup() runs once. draw() runs 60 times a second — forever. Change a variable inside draw() and that change becomes motion.

Try it in the Playground §2 Section overview

Concept 03 / 22

The big idea

A static sketch draws once. An animated sketch draws the same scene over and over, changing a value by a small amount each time. The difference between a painting and a movie is just: run draw() again with different numbers.

  • setup() — runs once at start; set canvas size here
  • draw() — runs in a loop, ~60 times per second
  • background() at the start of draw() clears the previous frame
  • Omit background() to get trails — each frame stacks on the last
  • frameCount — a built-in counter that increments every frame
  • frameRate(n) — control loop speed (default 60)

let x = 0;
let speed = 3;

function setup() {
  createCanvas(400, 200);
}

function draw() {
  background(240);

  x += speed;                    // move right every frame
  if (x > width || x < 0) {
    speed *= -1;               // reverse direction at edges
  }

  circle(x, height / 2, 40);
}

let x = 0, speed = 3;
const ctx = canvas.getContext('2d');

function loop() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  x += speed;
  if (x > canvas.width || x < 0) speed *= -1;

  ctx.beginPath();
  ctx.arc(x, canvas.height / 2, 20, 0, Math.PI * 2);
  ctx.fill();

  requestAnimationFrame(loop); // ~60fps
}

Processing / Java
float x = 0;
float speed = 3;

void setup() {
  size(400, 200);
}

void draw() {
  background(240);

  x += speed;
  if (x > width || x < 0) {
    speed *= -1;
  }

  ellipse(x, height / 2, 40, 40);
}

The canvas idea

Remove background() from draw() and run it. The trail that appears shows that the canvas doesn't erase itself — you have to erase it. This is the "aha" that makes the loop model tangible.

Then use frameCount directly: circle(frameCount % width, 100, 20) — no extra variables needed.

Key variables

  • frameCount — frames elapsed since start
  • frameRate() — get current FPS
  • millis() — milliseconds since start
  • width, height — canvas dimensions
  • noLoop() — pause the draw loop
  • loop() — resume the draw loop

Teacher notes

Timing: 2 periods. Spend the first on the setup/draw model with the trail demo. Spend the second on state variables and the bouncing ball.

Checkpoint: Students animate a shape using a variable that updates every frame, and can explain verbally why background() goes inside draw().

AP CSA: Connects to infinite loops — but intentional ones.
