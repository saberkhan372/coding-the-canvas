What CS Canvas covers in each Big Idea

CRD — Creative Development
All 22 concepts · strong throughout
Every CS Canvas concept asks students to design, prototype, and reflect on a visual artifact. CRD is structural — it's built into the canvas-output model, not layered on top. Every remix and checkpoint is CRD evidence.
DAT — Data
Strong in §5 · partial in §1, §4, §6
§5 (Data as Material, concepts 11–16) is the dense data core: images as pixel arrays, histograms, frequency analysis, color data pipelines. Earlier lessons touch data representation lightly; §6 touches data ethics and metadata.
AAP — Algorithms & Programming
Strong in §1–§4 and §7 · partial in §5–§6
The programming spine (§1–§4: shape, animation, variables, loops, functions, objects) gives full AAP coverage. §7 adds algorithm analysis — sorting and recursion beyond AP requirements. §5 and §6 use programming as a tool rather than the subject.
CSN — Computing Systems & Networks
Not covered — bring your own unit (~3 weeks)
Protocols, packets, DNS, fault tolerance, and parallel computing don't fit the canvas model. The canvas is the wrong medium for networking. Most AP CSP teachers already have a CSN unit — if not, the code.org Internet unit slots in cleanly.
IOC — Impact of Computing
Strong in §6 · partial in §5
§6 (Computing in the World, concepts 17–20) is dedicated to impact and ethics: bias in filters, accessibility of color, authorship of generated art, energy cost of computation. Each is grounded in a canvas artifact — the visual makes the impact concrete.

The one gap

CSN is ~3 weeks. Everything else is covered.

Computing Systems & Networks covers the internet, protocols, fault tolerance, and parallel computing. Teaching these through a canvas feels forced — the canvas is the wrong medium for networking. You'll need to bring your own CSN unit, but that's a manageable add.

  • CSN is typically 2–3 weeks in an AP CSP year
  • Most AP CSP teachers already have a CSN unit they like
  • The code.org Internet unit is the free, battle-tested option
  • Six 5-minute videos from code.org work well as a flipped component

AP Create Performance Task

Every sketch can become a Create PT.

The College Board requires a program with a list, a student-written procedure with a parameter, and an algorithm with sequencing, selection, and iteration. CS Canvas teaches all three. The §4 particle system checkpoint is designed to be CPT-ready — it has all three built in.

  • Array of objects = the required list
  • Class method with a parameter = the required procedure
  • For loop + boundary conditional = the required algorithm

Teacher FAQ

Do I need to teach every concept for AP CSP alignment?
No. §1–§4 covers CRD and AAP fully. Add §5 for DAT. Add §6 for IOC. Add your own CSN unit. §7 (recursion, sorting) exceeds AP requirements — useful enrichment but not required. See the 36-week AP CSP pacing guide for the recommended sequence.
What language do AP CSP students use?
p5.js. All three CS Canvas languages (p5.js, Canvas API, Processing Java) are offered per concept, but for AP CSP, p5.js is the right choice — it's JavaScript, runs in the browser without install, and the AP exam is language-agnostic.
Where does Create PT evidence come from?
The §4 section checkpoint (particle system) is designed to be CPT-ready: array of objects (list), class method with a parameter (procedure), for loop with a conditional (algorithm). Students who expand their §4 sketch instead of starting fresh usually finish Milestone 3 with time to spare. See the Create PT support page.
Does CRD really thread through everything?
Yes — intentionally. Every CS Canvas lesson produces a canvas artifact that students design, iterate, and reflect on. CRD isn't retroactively mapped onto programming lessons. The canvas-output model is a creative development process by design.
How does §5 cover data if students are just manipulating images?
Image pixels are data. When students read a pixel's RGB values, transform them through a function, and write them back, they're doing exactly what the DAT standard asks: representing data, transforming data, and observing how transformation changes output. The canvas makes the data pipeline visible.
Can I use CS Canvas for just part of my AP CSP course?
Yes. CS Canvas is modular. Many teachers use §1–§4 for the programming and CRD spine, then use a different curriculum for data and CSN. Each section works independently, though the full arc gives the most coherent student experience.
