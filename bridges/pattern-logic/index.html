concept bridge

Pattern Logic

A bridge for turning visual rules into loops, conditionals, and reusable drawing recipes.

Turn a pattern into a rule.

Pattern logic asks students to describe what they see before coding it. Once the visual rule is named, loops, conditions, and functions become tools for expressing it.

  • Notice repetition, alternation, symmetry, and variation.
  • Translate each visual decision into a rule.
  • Remix one rule at a time so cause and effect stay clear.

Bridge moves

See it

Ask students to circle what repeats and underline what changes.

Say it

Turn the observation into a sentence: every even column is orange.

Code it

Translate the sentence with a loop variable and a condition.

Teacher move

Keep the first rule simple, then invite controlled remixing.

Common snag

Students often change too many variables at once. Slow the remix down.

AP connection

Pattern logic supports algorithms, abstraction, conditionals, and procedural decomposition.

visual rule
for (let col = 0; col < 8; col++) {
  if (col % 2 === 0) {
    fill(217, 106, 61);
  } else {
    fill(28);
  }
  circle(40 + col * 36, 100, 24);
}
