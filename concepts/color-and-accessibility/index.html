Color & Accessibility

A palette is part of the interface. Contrast and color choices decide who can read and use what you make.

Try it in the Playground Section overview

Concept 18 / 22

The big idea

Students test their own sketches for contrast and color dependence. A beautiful palette can still be inaccessible. The goal is not to remove style, but to make style work for more people.

  • Measure contrast between foreground and background
  • Simulate color-vision differences
  • Avoid meaning by color alone
  • Add labels, patterns, or shape differences
  • Build an accessible palette

function luminance(r, g, b) {
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
}

let bg = luminance(246, 242, 234);
let fg = luminance(28, 26, 23);
let difference = abs(bg - fg);

if (difference > 120) {
  print('strong contrast');
}

The canvas idea

Put two versions of the same sketch next to each other: one using only color differences, another using color plus labels or patterns.

Patterns to notice

  • Contrast

  • palette testing
  • inclusive design

Teacher notes

Students can audit a previous sketch from the course. This makes accessibility feel like revision practice, not a separate lecture.

Common misconception: Accessibility is often treated as a checklist after the design is done. Here it is part of the sketching process.
