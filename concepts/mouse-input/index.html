Mouse Input

mouseX and mouseY are live variables — they hold the cursor's current position every single frame. Read them like any other number.

Try it in the Playground §3 Section overview

Concept 04 / 22

The big idea

The mouse is just two numbers: the column and row where the cursor currently sits. Those numbers update 60 times a second inside draw(). Pass them to circle() and you instantly have a sketch that follows your cursor — no event handlers, no callbacks.

  • mouseX — current cursor x position in pixels
  • mouseY — current cursor y position in pixels
  • mouseIsPressed — true while any button is held down
  • mousePressed() — function called once per click
  • pmouseX / pmouseY — previous frame's position (for trails)
  • dist(x1,y1,x2,y2) — distance between two points (hit detection)

function setup() {
  createCanvas(400, 300);
  background(240);
}

function draw() {
  // draw a line from previous to current position
  strokeWeight(4);
  line(pmouseX, pmouseY, mouseX, mouseY);

  // change color while pressed
  if (mouseIsPressed) {
    stroke(217, 106, 61);
  } else {
    stroke(28, 26, 23);
  }
}

function mousePressed() {
  background(240); // clear on click
}

let mx = 0, my = 0, px = 0, py = 0;
let pressed = false;
const ctx = canvas.getContext('2d');

canvas.addEventListener('mousemove', e => {
  px = mx; py = my;
  mx = e.offsetX; my = e.offsetY;
  ctx.strokeStyle = pressed
    ? 'rgb(217,106,61)'
    : 'rgb(28,26,23)';
  ctx.lineWidth = 4;
  ctx.beginPath();
  ctx.moveTo(px, py);
  ctx.lineTo(mx, my);
  ctx.stroke();
});
canvas.addEventListener('mousedown', () => pressed = true);
canvas.addEventListener('mouseup', () => pressed = false);
canvas.addEventListener('click', () =>
  ctx.clearRect(0, 0, canvas.width, canvas.height));

void setup() {
  size(400, 300);
  background(240);
}

void draw() {
  strokeWeight(4);
  if (mousePressed) {
    stroke(217, 106, 61);
  } else {
    stroke(28, 26, 23);
  }
  line(pmouseX, pmouseY, mouseX, mouseY);
}

void mouseClicked() {
  background(240);
}

The canvas idea

Start with just circle(mouseX, mouseY, 20) inside draw() — no setup needed. The circle follows the cursor instantly, no explanation required. Then ask: "what do you think mouseX is right now?"

Print the values: text(mouseX + ", " + mouseY, 10, 20) — students can see the coordinate pair update live.

Input reference

  • mouseX, mouseY — current position
  • pmouseX, pmouseY — last frame's position
  • mouseIsPressed — boolean (variable)
  • mousePressed() — called once per click
  • mouseReleased() — called on button up
  • keyIsPressed, key — keyboard equivalents

Teacher notes

Timing: 1–2 periods. This pairs well with Concept 05 (Conditionals) — they're natural together.

Key distinction: mouseIsPressed (a variable, true/false every frame) vs mousePressed() (a function called once per click). Students confuse these.

Checkpoint: Students build a "paint" app where holding the mouse draws and releasing stops.
