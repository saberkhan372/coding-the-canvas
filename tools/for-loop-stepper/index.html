For Loop Stepper

A classroom tool concept for slowing a for loop down until every part is visible.

Watch the loop think.

Students often see a loop as one mysterious block. The stepper breaks it into initialization, condition, body, and increment so each dot on the canvas matches one pass through the loop.

  • Track i before and after each step.
  • Show the condition result before the body runs.
  • Connect each iteration to one visible mark.

Loop state

i = 3

condition true: draw dot at column 3, then increment.

inittestbodyincrement

Classroom flow

Initialize

Set i to the first value and show where that value will draw.

Test

Ask whether the condition is true before drawing anything.

Body and increment

Draw one mark, then update i and repeat the question.

Use in class

Pause after each dot and ask students to predict the next value of i.

Debug habit

Compare i < count with i <= count to expose off-by-one errors visually.

Extension

Move from one loop to nested loops once the single counter feels stable.
