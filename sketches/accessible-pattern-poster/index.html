Accessible Pattern Poster

A poster seed that communicates categories with color and pattern, not color alone.

Open p5.js editor All sketches

What this seed teaches

This seed turns accessibility into a making problem: students can see why labels and patterns help when color is not enough.

p5.js starter
let labels = ["A", "B", "C", "D"];
let colors = ["#d96a3d", "#6aa7a0", "#1c1a17", "#ece5d6"];

function setup() {
  createCanvas(500, 320);
  noLoop();
}

function draw() {
  background(246, 242, 234);
  textAlign(CENTER, CENTER);
  textSize(18);

  for (let i = 0; i < 4; i++) {
    let x = 70 + i * 105;
    fill(colors[i]);
    stroke(28);
    rect(x, 80, 78, 120);

    stroke(28);
    for (let y = 90; y < 195; y += 16) {
      if (i % 2 === 0) line(x + 8, y, x + 70, y);
      else line(x + 12, y - 8, x + 66, y + 8);
    }

    noStroke();
    fill(i === 2 ? 255 : 28);
    text(labels[i], x + 39, 140);
  }
}

Try this

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Remove the patterns and ask what becomes harder to read.
  • Add a legend under the four categories.
  • Use shape differences instead of line patterns.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
