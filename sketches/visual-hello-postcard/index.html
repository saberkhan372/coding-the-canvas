Visual Hello Postcard

A first sketch that introduces a person, place, class, or community through shapes and color.

What this seed teaches

Use this as the first shareable artifact. The goal is not realism; it is making a visible choice and explaining it.

p5.js starter
function setup() {
  createCanvas(500, 500);
  colorMode(HSB, 360, 100, 100);
}

function draw() {
  background(35, 20, 96);
  noStroke();

  fill(18, 80, 86);
  rect(70, 300, 360, 90);

  fill(210, 70, 75);
  circle(155, 190, 110);

  fill(48, 90, 95);
  triangle(300, 135, 385, 330, 215, 330);

  fill(20);
  textSize(24);
  text("hello from my world", 92, 385);
}

Try this

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Change the palette to match a mood or place.
  • Replace one shape with a symbol from your classroom or community.
  • Add a title and one sentence explaining what the sketch represents.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
