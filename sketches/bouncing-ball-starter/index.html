Bouncing Ball Starter

The classic first-motion sketch: one ball, two velocities, four walls, and a visible reason for conditionals.

Open p5.js editor All sketches

What this seed teaches

Ask students to predict which line makes the ball reverse. This is a clean entry to conditionals because the bug is visible.

motionvariablesconditionalsbounce
p5.js starter
let x = 80;
let y = 120;
let vx = 3;
let vy = 2;

function setup() {
  createCanvas(500, 320);
}

function draw() {
  background(246, 242, 234);
  x += vx;
  y += vy;

  if (x < 20 || x > width - 20) vx *= -1;
  if (y < 20 || y > height - 20) vy *= -1;

  fill(217, 106, 61);
  circle(x, y, 40);
}

Try this

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Change speed and radius; then repair the wall checks.
  • Add a color change every time the ball bounces.
  • Add a second ball with different velocity.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
