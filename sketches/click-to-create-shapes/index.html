Click-to-Create Shapes

Every click stamps a new object into an array, giving events and collections an immediate payoff.

Open p5.js editor All sketches

What this seed teaches

Compare `mousePressed()` with checking `mouseIsPressed` inside draw. One is an event; one is a state read.

eventsarraysobjectsstamping
p5.js starter
let shapes = [];

function setup() {
  createCanvas(500, 320);
}

function draw() {
  background(246, 242, 234);
  for (let s of shapes) {
    fill(s.c);
    noStroke();
    circle(s.x, s.y, s.size);
  }
}

function mousePressed() {
  shapes.push({
    x: mouseX,
    y: mouseY,
    size: random(18, 56),
    c: color(random(255), random(160), 90)
  });
}

Foundation

Run the sketch and point to the line that creates the most important visual change.

Exploration

  • Make rectangles or triangles instead of circles.
  • Limit the array to the latest 20 shapes.
  • Add keyboard controls to clear or change the stamp mode.

Classroom adaptation

Write a two-sentence prompt for students: what should they change, and what should they explain?
