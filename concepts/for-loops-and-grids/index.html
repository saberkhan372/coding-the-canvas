For Loops & Grids

A loop draws 100 circles in 3 lines. Nested loops fill the entire canvas. i is just a number — but what you multiply it by becomes the pattern.

Concept 06 / 22

The big idea

Repetition without loops means copy-pasting code. With a loop, you write the rule once and let the counter (i) do the work. On the canvas, the pattern of shapes is the evidence that the loop ran — and each change to the loop makes the pattern change.

  • for (init; condition; update) — the three parts of a loop
  • i is the counter variable — it tracks how many times the loop has run
  • i * spacing — mapping the counter to a pixel position
  • Nested loops — one loop inside another makes a 2D grid
  • The outer loop controls rows, the inner loop controls columns
  • n² shapes from n×n nested loops

let cols = 8;
let rows = 6;

function setup() {
  createCanvas(400, 300);
}

function draw() {
  background(240);

  let spacingX = width / cols;
  let spacingY = height / rows;

  for (let i = 0; i < cols; i++) {
    for (let j = 0; j < rows; j++) {
      let x = i * spacingX + spacingX / 2;
      let y = j * spacingY + spacingY / 2;
      circle(x, y, spacingX * 0.6);
    }
  }
}

const ctx = canvas.getContext('2d');
const cols = 8, rows = 6;
const sx = canvas.width / cols;
const sy = canvas.height / rows;

for (let i = 0; i < cols; i++) {
  for (let j = 0; j < rows; j++) {
    const x = i * sx + sx / 2;
    const y = j * sy + sy / 2;
    ctx.beginPath();
    ctx.arc(x, y, sx * 0.3, 0, Math.PI * 2);
    ctx.fill();
  }
}

The canvas idea

Start with a single circle. Then ask: "how would you draw 10 of them in a row?" Students will want to copy-paste. After 3, the pain motivates the loop.

The grid is the payoff: 48 circles from 8 lines of code. Change cols from 8 to 20 and watch the grid update instantly.

Loop anatomy

for (
  let i = 0;    // init: start value
  i < 10;        // condition: keep going?
  i++            // update: add 1 each time
) {
  // body: runs 10 times (i=0..9)
}

Teacher notes

Timing: 2–3 periods. Spend time on the single-loop before introducing nesting.

Use the Stepper: The For Loop Stepper tool lets students step through the loop one phase at a time (INIT → CHECK → BODY → UPDATE). Invaluable for making the loop model concrete.

Checkpoint: Students modify the grid so circles scale with their distance from center, or color varies with i+j.
