Share & Export Flow

Guidance for saving images, copying code, and preparing classroom-safe ways to share sketches.

Save the evidence of learning.

A finished sketch is more useful when it travels with the code and a short explanation. This flow turns visual work into portfolio evidence students can revisit.

  • Export or screenshot the canvas output.
  • Copy the code that produced the result.
  • Add a caption naming the concept and the change.

Classroom flow

Capture the canvas

Save the final image or take a screenshot that shows the visible result.

Attach the code

Copy the smallest meaningful snippet, not necessarily the whole project.

Reflect briefly

Ask for one sentence: what changed, what caused it, and what was hard?

Use in class

End each major concept with one artifact students can submit or add to a portfolio.

Privacy habit

Use classroom-safe links and avoid publishing student names inside sketches.

Assessment

Grade the connection between image, code, and explanation rather than polish alone.
