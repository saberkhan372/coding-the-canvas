Modulo Bridge

A visual bridge for cycles, wrapping, repeated patterns, and clock-like logic.

Use remainders to make patterns loop.

Modulo is easiest to feel when something wraps: a dot leaves the right side and returns on the left, colors repeat every third item, or a clock resets after 12.

  • Use % to keep values inside a range.
  • Alternate choices without long if/else chains.
  • Name the pattern before naming the operator.

Bridge moves

Wrap position

Use x = (x + speed) % width so motion stays on the canvas.

Cycle style

Use i % 3 to choose a color, shape, or rhythm.

Debug the remainder

Print i and i % n side by side until the repeating sequence is visible.

Teacher move

Draw a number line that bends into a loop. Remainders become locations around the loop.

Common snag

Students may read % as percent. Say “remainder after division” every time at first.

AP connection

Modulo supports loop patterns, bounds logic, simulations, and algorithmic thinking.
