The tool suite is a teaching layer, not a replacement for lessons. Use a tool for a live demo, a station rotation, or a quick “play before reading” moment, then send students to a starter sketch or concept page.

  • Open one tool before explaining the syntax.
  • Ask students to predict before moving a slider.
  • Move from tool → sketch → concept explanation.
