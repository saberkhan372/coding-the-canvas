Objects

A Ball knows its x, y, and speed. It knows how to move itself and draw itself. That's an object — data and behavior bundled together.

Try it in the Playground §4 Section overview

Concept 09 / 22

The big idea

When a sketch has many parallel arrays — xPos[], yPos[], speed[] — managing them is error-prone. An object groups related values into one unit. A Ball object holds its own x, y, and speed, and knows how to update and draw itself.

  • Object literal: { x: 10, y: 20, r: 15 }
  • Class syntax: class Ball { constructor() { ... } }
  • this.x — refers to the object's own property
  • Methods: functions defined inside a class
  • new Ball() — creates an instance
  • Array of objects — the foundation of particle systems

class Ball {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.r = random(10, 30);
    this.vx = random(-3, 3);
    this.vy = random(-3, 3);
  }

  move() {
    this.x += this.vx;
    this.y += this.vy;
    if (this.x < 0 || this.x > width)  this.vx *= -1;
    if (this.y < 0 || this.y > height) this.vy *= -1;
  }

  draw() {
    circle(this.x, this.y, this.r * 2);
  }
}

let balls = [];

function setup() {
  createCanvas(400, 300);
  for (let i = 0; i < 10; i++) {
    balls.push(new Ball(random(width), random(height)));
  }
}

function draw() {
  background(240);
  for (let b of balls) {
    b.move();
    b.draw();
  }
}

class Ball {
  constructor(x, y) {
    this.x = x; this.y = y;
    this.r  = Math.random() * 20 + 10;
    this.vx = (Math.random() - 0.5) * 6;
    this.vy = (Math.random() - 0.5) * 6;
  }
  move() {
    this.x += this.vx;
    this.y += this.vy;
    if (this.x < 0 || this.x > W) this.vx *= -1;
    if (this.y < 0 || this.y > H) this.vy *= -1;
  }
  draw(ctx) {
    ctx.beginPath();
    ctx.arc(this.x, this.y, this.r, 0, Math.PI*2);
    ctx.fill();
  }
}

class Ball {
  float x, y, r, vx, vy;

  Ball(float x, float y) {
    this.x = x; this.y = y;
    this.r  = random(10, 30);
    this.vx = random(-3, 3);
    this.vy = random(-3, 3);
  }

  void move() {
    x += vx; y += vy;
    if (x < 0 || x > width)  vx *= -1;
    if (y < 0 || y > height) vy *= -1;
  }

  void draw() {
    ellipse(x, y, r*2, r*2);
  }
}

The canvas idea

Start with three parallel arrays (xPos[], yPos[], speed[]) and point out how you have to update three arrays every time you add a property. Then refactor into a class — students can feel the simplification immediately.

10 balls bouncing on screen, each managing its own state. The canvas is the proof that encapsulation is working.

Key terms

  • Class — the blueprint/template
  • Instance — one specific object
  • Constructor — runs when created
  • Property — a variable belonging to an object
  • Method — a function belonging to an object
  • this — refers to the current object

Teacher notes

Timing: 2–3 periods. The refactor exercise (arrays → class) is the most impactful activity.

Java path: Processing/Java syntax requires typed fields and a constructor matching the class name — this is good preparation for AP CSA Unit 5 (Writing Classes).

Checkpoint: Students create an array of 20 objects, each with at least 3 properties and 2 methods (move + draw).
