Conditionals

if / else — the canvas asks a yes/no question every frame. The answer decides which branch of code runs. Boolean is just another word for yes or no.

Try it in the Playground §3 Section overview

Concept 05 / 22

The big idea

A conditional is a fork in the road. The program checks a condition — a question with a yes/no answer — and takes one of two paths. On the canvas, those two paths produce visually different results, making the logic immediate and testable.

  • Boolean: a value that is either true or false
  • if (condition) { ... } — runs block if condition is true
  • else { ... } — runs if condition is false
  • else if — chains multiple conditions
  • Comparison operators: ==, !=, <, >, <=, >=
  • Logical operators: && (and), || (or), ! (not)

function setup() {
  createCanvas(400, 300);

function draw() {
  background(240);

  // which zone is the mouse in?
  if (mouseX < width / 3) {
    fill(100, 150, 220);        // left: blue
  } else if (mouseX < (width / 3) * 2) {
    fill(100, 200, 100);        // middle: green
  } else {
    fill(217, 106, 61);         // right: orange
  }

  noStroke();
  circle(mouseX, mouseY, 60);
}

The canvas idea

Divide the canvas into two colored halves. A circle drawn at mouseX shows which half the cursor is in. Change the fill based on position — the divide is immediately visible.

Then ask: "what would happen if the circle turned red when you click?" That question naturally leads to mouseIsPressed combined with a boolean condition.
