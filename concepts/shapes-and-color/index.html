Shapes & Color

rect, ellipse, line — the primitive vocabulary. fill and stroke let you paint each shape any color in the 16-million-color RGB space.

Try it in the Playground §1 Section overview

Concept 02 / 22

The big idea

Every mark on the canvas is made with a primitive shape function. You set a fill color and a stroke color before drawing — everything drawn after inherits those colors until you change them. This "paint state" model is how most graphics systems work.

  • rect(x, y, width, height) — rectangle from top-left
  • ellipse / circle — placed at center by default in p5
  • line(x1, y1, x2, y2) — straight line between two points
  • fill(r, g, b) — sets the interior color
  • stroke(r, g, b) — sets the border color
  • noFill() / noStroke() — removes fill or border entirely

function draw() {
  background(240, 237, 228);

  // dark rectangle
  fill(28, 26, 23);
  noStroke();
  rect(40, 40, 120, 80);

  // orange circle — no fill, just stroke
  noFill();
  stroke(217, 106, 61);
  strokeWeight(4);
  circle(280, 150, 120);

  // line
  stroke(0);
  strokeWeight(2);
  line(40, 200, 360, 200);
}

The canvas idea

Start with: "how would you describe a blue square to someone who can't see your screen?" The answer is always coordinates, size, and color — exactly what these functions encode.

Key demo: change fill color between two rect() calls to show that color is "paint in the brush," not a property of the shape.

Shape reference

  • rect(x, y, w, h) — top-left corner
  • circle(x, y, d) — center, diameter
  • ellipse(x, y, w, h) — center
  • line(x1, y1, x2, y2)
  • triangle(x1,y1, x2,y2, x3,y3)
  • point(x, y) — single pixel

Teacher notes

Timing: 1–2 periods. Combine with Concept 01 into a single "first sketch" lesson.

Checkpoint: Students reproduce a given target image (provided as a screenshot) using at least 4 different shape types with intentional colors.

Extension: Introduce colorMode(HSB) in p5 for students who want more intuitive color control.
